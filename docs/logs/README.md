## 维护规则

1. 新日志优先追加到对应日期文件。
2. 日期文件使用 `# 开发日志 YYYY-MM-DD` 作为一级标题。
3. 每个阶段使用 `## YYYY-MM-DD 主题` 作为二级标题。
4. 不在 `开发日志.md` 中维护全文；该文件只作为兼容入口。
5. 新增日期文件后，同步更新本索引和上级 `docs/README.md`。
