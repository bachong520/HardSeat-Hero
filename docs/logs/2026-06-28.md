# 开发日志 2026-06-28

## 2026-06-28 S06 流式最低价快照协议

### 目标

将原先“流式接口只逐个输出方案”的行为升级为实时最低价快照。用户查询时，前端能持续看到当前已发现的最低价 Top N；后续出现更低价方案时，旧方案会被自动移出结果列表。

### 已完成成果

- `RouteSearchService` 新增 `stream_snapshots()`，在当前 Top N 发生变化时输出 `type=snapshot` 快照。
- `POST /api/routes/search/stream` 改为输出 NDJSON 事件流：
  - `type=snapshot`：当前最低价 Top N、已搜索候选数、待完成候选数、远程请求数、当前耗时。
  - `type=metadata`：流结束元数据和最终耗时。
  - `{ "error": "..." }`：保留现有错误行格式。
- 前端流解析支持 snapshot 事件，收到快照后整体替换结果列表，实现更优方案出现时自动删除被挤出的旧方案。
- 前端状态区新增实时快照信息：已搜索候选、待完成候选、当前展示 Top 数。

## 2026-06-28 S06 类型修复：流式快照 Pylance 告警

### 问题

`RouteSearchService.stream_snapshots()` 的返回类型原先写为 `dict[str, object]`，导致 Pylance 在 API 层只能把 `snapshot["plans"]` 和 `snapshot["updated_at"]` 推断为 `object`，从而报出 `object` 不可迭代和 `object.isoformat` 不存在。

### 修复

- 将 `StreamSnapshot` 改为 `TypedDict`，明确 `plans` 为 `list[TransferPlan]`、`updated_at` 为 `datetime`，并将 `final` 标记为可选字段。
- `POST /api/routes/search/stream` 不再原地改写服务层快照，而是构造序列化用 `payload`，避免把领域对象快照变成 JSON 字典后破坏类型语义。
